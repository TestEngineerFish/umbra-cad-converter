# 这里没有 dwg 夹具，而那不是漏了

两条理由，第二条更要紧：

**① 我们没有能力造一份 dwg。** LibreDWG 在这个封装里只读不写，
这个仓库里也没有别的东西能写 dwg。手里有的 dwg 全是**客户的图纸**，
而那些**一个字节都不进任何仓库**（Studio 的纪律，`CLAUDE.md` §6 ⑥）。

**② 从网上随便抓一份 dwg 当夹具，是把一个来源不明的二进制文件放进一个公开仓库。**
它的许可、它里面有什么，我们都说不清。

所以分工是这样的：

| 测什么 | 在哪 | 怎么测 |
| --- | --- | --- |
| **契约**：`--version` / 参数不全 / 文件读不了 / 产物装配对不对 | 这里（`npm run selftest`） | 不需要 dwg |
| **端到端**：一份图读进来变成什么 | Studio 的 `cadtest` | 它有**自拟的** sample JSON 夹具，走一个假转换器 |
| **真图**：真实项目的 dwg 读得对不对 | 人工，在本机 | 图纸不进仓库，读数写在 Studio 的 `doc/00` |

> ⚠️ **「这一层没有判据」和「这一层的判据在别处」要分清。**
> 写在这儿就是为了下一个人不用去猜是哪一种。
